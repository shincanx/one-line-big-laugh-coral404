Entry for the [make.fun bounty "One Line, Big Laugh"](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857): a program that writes one single hilarious line, 200 characters or fewer, that lands entirely on its own — no title, setup, or explanation around it.

## The line

> My GPS sighed when I asked for the fastest route home: 'Therapy -- and I'm not elaborating.'

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Deterministic, no network, no input. The program writes exactly the line above to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output`, or a local `output/` folder).
